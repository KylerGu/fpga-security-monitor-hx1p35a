# 功能与操作

硬件为 HX1P35A V1.0（PH1P35MDG324）与 SC520CS 摄像头，输出 1280×720 HDMI 画面。功能包括摄像头采集、帧缓存、灰度/边缘处理、运动告警、红色目标定位、双向越线计数、自动曝光、固定提亮、手动调焦辅助和图文叠加。白平衡及底层视频模块沿用厂商例程。

| 控件 | 行为 |
|---|---|
| KEY1 | 复位为 RAW、默认警戒区、撤防、默认 S2；清 CNT、PASS 和方向计数 |
| KEY2 | RAW → GRAY → EDGE → MOTION → PASS → RAW |
| KEY3 | RAW 下循环红色灵敏度 S0～S3；其他场景返回 RAW |
| KEY4 短按松开 | 布防/撤防 |
| KEY4 按约 3 秒后松开 | 只清告警 CNT，保持布防和 PASS 计数 |
| SW1 | 设置警戒区并撤防；SET 下 KEY2 选择位置/尺寸，KEY3 减、KEY4 加 |
| SW2 | 按冻结操作记录：拨下为 AE，拨上为 FX 320；以实际屏幕 AE/FX 状态为准 |
| SW3 | 显示/隐藏中心调焦框、F 当前分数和 P 本次峰值 |
| SW4 | 任意方向稳定拨动，重置调焦参考 |
| SW5 | 板载蜂鸣器硬件开关，不是 FPGA 软件输入 |

原引脚文件中 SW2 的方向注释与操作记录不一致，本次不改冻结文件；操作时以屏幕状态为准。SW1 的运行/设置档也以 DISARM、ARMED、SET 字样确认。

日常使用 RAW 与 AE；固定摄像头和目标，等曝光稳定及 WAIT 结束后观察。SW3 留在开启位置时，上电出现调焦框是正常行为。微调镜头后松手等画面稳定，结合文字清晰度和 F 的趋势判断；P 不是最佳焦点标准值，移动、亮度和噪声都会影响分数。

安防步骤：设置警戒区 → 退出 SET → 确认 DISARM → KEY4 布防 → 区域内运动触发 LED/蜂鸣器 → 静止后约 2 秒解除 → KEY4 撤防。连续 5 个有效运动帧确认触发，一段持续告警只增加一次 CNT。大面积亮度突变可触发 LIGHT 保护。超过约 500 ms 无完整检测帧时标记中断，恢复后重新累计运动确认帧；中断时已有告警保留。

越线演示：KEY2 到 PASS；固定摄像头，只用一个红色目标，在画面左侧停稳约 0.3 秒，缓慢移到右侧停稳，再返回左侧。中心线 x=640，缓冲区 ±24 像素，两侧各连续 3 帧确认；预期 PASS 增加 2，L>R、R>L 各加 1。首次出现、线边停留、目标丢失后重现均不补计。LAST 为最近方向，SIDE 为确认起点。

只有 PASS 场景显示黄色线、缓冲虚线和新增计数；其他场景后台计数继续，切换场景不清零。SET 暂停关联；灵敏度变化、无效/缺失/重复帧、断流后重新建立起点。PASS 与告警 CNT 独立，不受布防或警戒区控制，最大 999，断电不保存。

PASS 是目标通过次数，不是人数；多个红目标会合并一个外接框。没有独立目标 ID、多目标跟踪或指定方向报警。红色定位本身不会单独触发运动告警。FPS 为摄像头帧率；LAT 为缓存帧号差，不能直接当作端到端显示延迟。
